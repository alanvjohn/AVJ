# Cybersecurity learning roadmap

## Foundations

- Linux command line and file permissions.
- HTTP, DNS, TLS, cookies, and browser security.
- Authentication versus authorization.
- Secure password storage and session management.

## Portfolio projects

1. Document the Firebase Message Vault threat model.
2. Build a local OWASP practice application for defensive learning.
3. Create a security headers checker for websites you own or are authorized to test.
4. Build a small log-monitoring dashboard with severity labels.

## Documentation format

For each project, record:

- The assets being protected.
- The likely threat or abuse case.
- The defensive control implemented.
- How the control was tested.
- Remaining limitations.

Only test systems that you own or have explicit permission to assess.
